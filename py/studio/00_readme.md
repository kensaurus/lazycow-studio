# py/studio

| Module | Role |
|---|---|
| ingest | Catalog and 720p proxies. `library --ingest` walks the media root and every `config.extra_sources()` folder. Read-only sources. GPS sets `near_ranch`. `is_output` keeps studio renders, Drive copies and finished edits (`*_reel_*`, `*_9x16*`) out of the footage. |
| library | **The tagged library.** CLIP ViT-B-32 embedding, zero-shot tags (`VOCAB`, JA labels), YuNet faces, sharpness, event (dated folder), season, time of day, keyframe thumbs. `items(query, filters)` searches in plain words and returns place, tags and `usedIn` (which reels use each file). `place_from` decides where a file was shot: own GPS, then its folder, then its event folder (files from before the event date count as the trip there), then the event folder's name. Per clip it also stores the worst keyframe's `person` and `junk` (filler) scores, and `veto` records a person's "never auto-pick". |
| assemble | **Reel proposals from a theme.** 17 themes (office, carstay, autumn, fire, field, warm, loud, lookup, focus, connect, aerial, and the staged reasons, day, seasons, pov, nightfire, altitude), every word from the website SSOT. One plain-word search per story slot; ranked by match with small nudges (recent +0.02, the theme's season or tag +0.04, each reel already using it −0.06); no people unless allowed, no filler, no vetoed clips, photos at most 30%, near-duplicates skipped; `device` limits a theme to drone footage. Shot lengths then move onto the theme's music (`fit_cuts`, still on the 0.5 s grid) and the project stores `bpm`. Captions start on the cut of their cue slot; each theme has a text `style`. Each slot keeps its four best eligible clips and `draw()` picks one, weighted by exp((score − best) / `VARIETY`) with a seeded RNG; the project stores `seed`, `variety` and `trace` (search line, candidates, scores, pick). `film_next` lists themes with fewer than three fresh opening clips. `alternate_opening` copies a reel and swaps the first shot. Saves a project with approved post copy. |
| staging | **Looks and recipes** (`shared/looks.json`, `src/looks.tsx`). `staging(reel)` resolves look, recipe, kicker and loop: the project's own, else its theme's (an editor save may drop them). Marks from each clip's data: 朝/昼/夕/夜 from darkness and capture hour in Japan time, 春/夏/秋/冬 from capture month. `number_lines` numbers countdown lines. |
| projects | Editor-made reels as `projects/<slug>.json`; they override house reels of the same slug. Optional `theme`, `music` (`"auto"`, `"off"` or `{id, volume, start}`) and `sfx` (bool). |
| sound | **Music and effects.** CC0 / public-domain tracks from the Openverse API (no key; Freesound, Wikimedia, Jamendo) saved in `<data>/audio` with a licence sidecar; whoosh / riser / hit synthesised locally. Picks a bed per theme mood (skipping a track's silent intro), places a whoosh into each caption cut, a riser and a hit on the end card, auto-ducks the music under clip sound, one loudness pass. Writes `credits.txt` for every delivery. |
| service | Long-lived JSON-line helper for the editor (CLIP loads once): library, asset, ids, themes, assemble, save_project (rule, location, source and copy checks), project, overview (dashboard, with `shot_checks` and `filmNext`), review, audio_list, audio_fetch, veto, autopilot (one proposal per theme from the newest footage), alternate (a second opening). |
| shots | Scene cuts, keyframes, sharpness, motion, faces, optional OpenCLIP. |
| tag | Gemini Flash tags via OpenRouter, spend log, daily cap. |
| shot | **House grade.** Measures each clip, normalises levels, S-curve, warm highlights, cool shadows, vignette, grain. The output window follows a face, or else the sharpest part of the frame, across and down. `blur=True` softens each detected face before the crop. HLG/PQ clips are tone-mapped first. Photos are flattened through Pillow (`open_photo`: HEIC/AVIF via pillow-heif, RAW/DNG via rawpy). A 360 source goes to `_render_360` instead of the crop: `flat_photo` caches a stitched sphere as `sphere_*.png` (came stitched) or `stitch_*.png` (stitched here, rough seams: pans only). `before_after` writes a split frame as proof. |
| sphere | **360.** `is_equirect` (2:1, ≥2000 px, or `.insp`), `layout` (stitched vs two lens circles), `stitch_still` (tries four lens orientations, keeps the lowest `seam_cost`), `level` (six whole-sphere turns, keeps the one with sky on top; no gyro data is read), `side_by_side` (Insta360 DNG's stacked lenses), `front_view` (a level normal-lens view for tags and thumbs). `chain(move, seconds, size, script)` writes one sendcmd keyframe per frame (smoothstep ease) for ffmpeg `v360`: `pan`, `reveal`, `planet` (stereographic, pitch −90) and `unroll`. `move_for(i, kind, n)` gives a reel its moves. |
| sources | **Footage folders.** `roots()` (drives on Windows / macOS / Linux, Google Drive, home folders), `listdir`, `discover(path)` (counts by kind, format and year, 360, size, already catalogued, outputs and graphics skipped; stat only, opens no file), the registry `<data>/sources.json` (`add(path, mode)`: `trusted` or `gps`), and `diff()` (new files on every source vs the catalog, saved to `sources_state.json`). `sources watch` diffs, ingests and tags; the server runs it on a timer. |
| aesthetic | **LAION aesthetic predictor** (MIT): a linear head on the stored OpenAI CLIP ViT-B/32 embedding, 1–10. `library.items` adds `aesthetic`; `assemble` nudges by at most ±0.02 and keeps it in the trace. The head lives in `<data>/bin`; without it nothing changes. |
| media | Read-only probes and **the list of formats** (`VIDEO`, `PHOTO` for ingest, `STILL` for anything the renderer shows, `RAW`). RAW sizes from rawpy; GPS and time from the JPEG / INSP beside it. |
| reel_specs | **The house reels** (`view`, `fire`, `field`, `winter`): 1-2 s shots on a 0.5 s grid, one hold. |
| pick | Best 1-2 s of a clip by sharpness and motion; YuNet face count for the window. |
| reels | **Build and package** house reels and projects. `check_reel` enforces the editorial rules; the location gate refuses off-site files and the source gate refuses finished edits. Words only from the website SSOT lines. Each size gets a clean master (clip sound) and a scored master (music + effects); `remix` redoes only the sound. Writes one draft folder per channel (sizes in `shared/channels.json`), plus a `_no-music` copy for Instagram and TikTok and `credits.txt` everywhere. Prints `STAGE n/7` lines for the dashboard. `set_cover(slug, t)` re-cuts every network's cover from one moment (kept as the project's `coverAt`). `place_words` measures each caption's shot and puts the line on the side where the picture is quiet. |
| looks / grade | House 3D LUTs and the first cut's mezzanines, kept for `deliver`. The cut styles ("looks" such as `whip` or `glitch`) are a different thing: `shared/looks.json`, `src/looks.tsx`, drawn by `service.vary_look`. |
| edl / guard | Shot pick (skips off-site GPS), captions, fact guard. |
| deliver / render | First-cut pipeline and the shared Remotion + loudness helpers. |
| youtube | **Posting to YouTube.** One-time OAuth for an installed app (PKCE, loopback to the studio), refresh token encrypted for the Windows user (DPAPI) in `<data>/secrets`. `upload(slug, at, privacy)` sends the reel's youtube-shorts file with the approved title and description plus hashtags and the music credit; `at` schedules it (private until then). Refuses a reel already on the channel. `list_videos()` reads the channel. Bilingual playlists (`PLAYLISTS`): `sort_into_playlists()` creates the ones it needs and adds public and scheduled videos by reel theme or title words; a new public or scheduled upload joins its playlists. Needs the `youtube` scope (Connect again once). |
| activity | **The Log page's data**: paid AI spend (the `spend` table), the local models, each reel's assembly trace (or one rebuilt from its shot roles), finished jobs from `renders/jobs.jsonl`, YouTube uploads. Read-only. |
| gphotos | **Google Photos Picker API**: connect once (scope `photospicker.mediaitems.readonly`), open a picking session, download exactly the picked items into `<data>/imports/google-photos/<date>/`, then ingest and tag them. Already-imported items are skipped. |
| posting | **The posting log** (`posts` table) for every network: `planned` (a reminder), `scheduled` (booked on the site), `queued` (the studio sends it at the time), `posted`, `failed`; the live link after posting, and an `.ics` calendar reminder per plan. A scheduled post whose time has passed counts as posted. `skip(slug)` marks a reel not to be posted. |
| publish | **Posting from the studio** to a connected network: `connections()`, `publish(slug, net, at)` (schedules where the network can, else queues), `--due` sends queued posts whose time has come. It does not check the review status (see `docs/HANDOFF.md`). Connectors in `connectors/`: `facebook` (Page Reels through the Graph API with the owner's Meta app; a 60-day user token, a Page token that does not expire), `bluesky` and `bluesky_oauth` (video posts; "Sign in with Bluesky" lasts two weeks, an app password does not run out). |
| wording | **The word bank**: every approved headline and line (themes, website SSOT, the owner's own, approved AI suggestions in `shared/words.json`), use counts, `draw()` (least used lately, fits the shot, never another reel's set), `reword(slug)`, `suggest_lines()` (OpenRouter, approved copy only, saved as "suggested"). `python -m studio.wording report | draw | add | status | suggest | reword`. |
| layers | **V2**: `plan()` picks 0-2 cutaways or insets for a new reel, `check()` is their render gate, `render()` grades them and returns Remotion props. |
| perf | **How each reel did**: metric snapshots per post, collectors for YouTube, Facebook and Bluesky, manual entry and CSV import for the rest. `docs/perf-api.md`. |
| learn | **What worked**: Thompson sampling over theme, layout, look and length from `perf`, with a fixed share of exploration and plain-word uncertainty; steering stays off until 15 measured posts (`STUDIO_PERF_STEER=1` turns it on without asking). |
| footage | **Footage health**: reels of fresh footage left, reuse per clip, cameras (from each file's own make and model), and what to film next with which camera. |
| briefs, compare, verify, db | Fallback lines for the first reels; side-by-side with the older SNS cuts; a master's spec check (size, fps, codecs, loudness); the SQLite catalog. |
| review_actions | Approve copies a story reel's channel folders into the Drive `ready` folder (merges, never deletes). A person approves, not the build. Faces block approve unless consent is ticked or the project has `blurFaces`. |
| extras | Mask, parallax, Takeout, upscale, licensed beats, dry gap-fill. |
| research | **Research through Firecrawl** (read-only, `docs/research-api.md`): ideas and trends (web + news search, hashtags, keywords, post angles from OpenRouter inside the daily budget, else templates), a check of the brand website against the facts in the approved copy (`approved_facts()`; a number counts only when the page text writes it), a page read, local events with dates, and a check of every link in planned posts and the profile kit. 24 h cache and a daily request cap under `STUDIO_HOME/research`. Runs as `python -m studio.research <action>` with the request JSON on stdin. |
| ai | **AI assist** (`docs/ai-api.md`): one spend ledger (`charge()`: priced first from fal's pricing API / OpenRouter's model list, refused over the per-reel `STUDIO_AI_REEL_CAP_USD` (default $2), total `STUDIO_AI_TOTAL_CAP_USD` ($20) or the daily budget, recorded in `spend` with provider, model, purpose `ai-<tool>` and slug); the reviewer (a video model on OpenRouter, suggestions only); fal tools: sharpen (Topaz), slowmo (RIFE), living photo (Kling i2v, labelled), music (Stable Audio 2.5, instrumental), Japanese voice (MiniMax, labelled). Outputs go under `<data>/ai` (cached per source clip) and into the project (`shots[i].ai_clip`, `music`, `voice`, notes in `ai`); `reels.build` and `sound.mix` use them. Approved reels are never changed (`into` makes a copy). Key check / save to `.env`. `python -m studio.ai <action>`, request JSON on stdin. |

Commands: `python -m studio library --ingest --scan` (catalog and tag new footage), `python -m studio assemble <theme> <slug>`, `python -m studio reels --build <slug>`, `python -m studio reels --remix <slug>` (sound only), `python -m studio audio --synth | --seed | --fetch music "calm piano" | --list`, `python -m studio reels --plan`, `python -m studio youtube status | upload <slug> [--at …] | list`, `python -m studio posts list | plan | done | drop | ics | skip | unskip`, `python -m studio publish [slug net --at …] | --due`, `python -m studio footage health | cameras`, `python -m studio sources roots | ls PATH | discover PATH | add PATH --mode gps|trusted | remove PATH | list | diff | watch`, `python -m studio library --redo-360 --scan`.
