# py

Python package `studio`. Run from the repo root with `PYTHONPATH=py`.

Tests: `%STUDIO_DATA%\venv\Scripts\python.exe -m pytest` from this folder. `tests/test_sphere.py` covers 360 detection, the eased camera moves, seams and levelling; `tests/test_sources.py` covers formats, the footage-folder registry, browsing, discovery and the new-file diff.
