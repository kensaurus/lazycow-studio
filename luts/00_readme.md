# luts

House looks written by `python -m studio luts`: `tsumagoi-film`, `asama-dusk`, `clean`. They are .cube files for ffmpeg `lut3d`. The footage is already Rec.709, so these are a creative grade, not a log conversion.

A still of each look is written under `%STUDIO_DATA%\review\looks\<slug>\` when a reel is graded.
